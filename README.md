Site statique GitHub Pages. Copier les fichiers à la racine du dépôt, activer Pages sur `main` / `(root)`.

- Un seul thème visuel, sans bascule jour/nuit.
- Données existantes importées depuis `custom.json` (6 modules présents dans l'archive source ; ne pas confondre avec les 26 modules envisagés pour le catalogue final).
- Cours complets et chapitres issus de la source, modes cartes/liste, fiches présentes dans les données, bibliothèque de commandes avec options.
- Accueil et visuels recréés en HTML/CSS : les illustrations photographiques/3D exactes des maquettes ne sont **pas** encore intégrées.
- Veille, météo, TP et outils externes non encore branchés. Aucun faux flux d'actualité ou de météo.
- Archive de travail : ne pas considérer comme version finale 99 % fidèle.
