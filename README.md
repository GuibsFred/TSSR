# TSSR V2 — nouveau dépôt GitHub Pages

Cette archive est une **première base fonctionnelle de reconstruction**, pas encore la reproduction finale à 99 % des maquettes validées.

## Installation

Décompresser le ZIP et envoyer **le contenu** à la racine du nouveau dépôt GitHub (index.html à la racine). Dans Settings > Pages, choisir Deploy from a branch, main, / (root).

## Contenu

- Nouvelle interface : accueil, catalogue des modules (cartes/liste), chapitres, cours complets, fiches de révision, démonstration de bibliothèque de commandes.
- Les modules et cours sont lus depuis `custom.json` (copie des données fournies).
- `ancien-site/` conserve **intégralement** le site d'origine, ses outils, son éditeur et ses données.

## Limites connues

- L'éditeur et les QCM historiques ne sont pas encore intégrés dans la V2 : le lien ouvre le site d'origine embarqué.
- Les commandes V2 sont pour l'instant un échantillon de démonstration, pas encore une bibliothèque exhaustive.
- L'accueil V2 n'intègre pas encore le journal live, la météo ni les 3 écrans réalistes de la maquette.
- Les illustrations 3D de la maquette doivent encore être intégrées comme ressources individuelles.
- Le rendu n'est pas encore une reproduction à 99 % ; il doit être comparé et corrigé avec les maquettes.
- Les données locales éventuellement stockées dans le navigateur de l'ancien domaine GitHub Pages ne migrent pas automatiquement vers le nouveau domaine.

Ne supprimez pas l'ancien dépôt tant que la V2 n'est pas finalisée et testée.
