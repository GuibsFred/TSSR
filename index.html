Comprendre le démarrage de Debian

1.1 Les grandes étapes du démarrage

Lorsqu’un ordinateur démarre, plusieurs composants interviennent successivement avant que l’utilisateur puisse ouvrir une session. Le déroulement est le suivant :

  1. Mise sous tension
  2. BIOS / UEFI
  3. MBR / GPT
  4. GRUB2
  5. Noyau Linux
  6. systemd (PID 1)
  7. Cible + Services
ÉlémentRôle
BIOS / UEFIInitialise le matériel et recherche un amorçage.
MBR / GPTContient les informations de partitionnement et d’amorçage.
GRUB2Chargeur d’amorçage : propose le choix du système à démarrer.
Noyau LinuxCharge le noyau et les pilotes de base.
systemdPremier processus (PID 1) : gère l’initialisation des services.
ServicesLance les services du système (réseau, SSH, etc.) et la session utilisateur.

⚠ À retenir

GRUB2 est le point d’entrée du système. Il permet de choisir le noyau et de transmettre les paramètres de démarrage.

▤Fiche de révision – Module 03

  • Chaîne de démarrage : BIOS/UEFI → MBR/GPT → GRUB2 → noyau → systemd.
  • Rôle de GRUB2 : chargeur d’amorçage.
  • systemd (PID 1) : init moderne, gestion des services.
  • Commandes clés : systemctl, journalctl, shutdown…

⌨Commandes essentielles

CommandeDescription
systemctl status <svc>État d’un service
systemctl start <svc>Démarrer un service
systemctl stop <svc>Arrêter un service
systemctl restart <svc>Redémarrer un service
systemctl enable <svc>Activer au démarrage
systemctl disable <svc>Désactiver au démarrage

★Points clés

  • Le démarrage se fait en plusieurs étapes successives.
  • GRUB2 charge le noyau Linux.
  • systemd initialise le système et les services.
  • La commande systemctl permet de gérer les services.
